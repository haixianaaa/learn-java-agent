# s06: Context Compact

本章实现上下文压缩系统，当对话历史过长时自动压缩旧的 tool_result，避免超出模型上下文限制。

## 运行方式

```bash
cd s06-context-compact
mvn exec:java -Dexec.mainClass="com.claudecode.agent.s06.Main"
```

## 本章新增能力

- 实现 `microCompact()` 压缩旧的 tool_result
- 估算上下文大小
- 持久化大输出到文件
- 保存对话记录到 `.transcripts/` 目录

## 代码结构

```text
s06-context-compact/
├── src/main/java/com/claudecode/agent/s06/
│   ├── Main.java
│   ├── compact/
│   │   ├── CompactState.java    # 压缩状态
│   │   └── CompactUtils.java    # 压缩工具
│   └── model/
│       └── ...
└── pom.xml
```

## Micro Compact

保留最近 3 个 tool_result，压缩更早的结果：

```text
[Earlier tool result compacted. Re-run the tool if you need full detail.]
```

## 大输出持久化

当工具输出超过 30000 字符时，自动保存到文件：

```text
.persisted-output/
└── tool-use-id.txt
```

返回预览：

```xml
<persisted-output>
Full output saved to: .persisted-output/tool-use-id.txt
Preview:
... (前 2000 字符)
</persisted-output>
```
