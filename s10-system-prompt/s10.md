# s10: System Prompt

本章实现结构化的 system prompt，统一管理角色、约束、技能、记忆和动态上下文。

## 运行方式

```bash
cd s10-system-prompt
mvn exec:java -Dexec.mainClass="com.claudecode.agent.s10.Main"
```

## 本章新增能力

- 新增 `SystemPrompt` 结构体
- 使用 Builder 模式构造 prompt
- 加载 `CLAUDE.md` 文件
- 注入动态上下文（日期、工作目录、平台）

## 代码结构

```text
s10-system-prompt/
├── src/main/java/com/claudecode/agent/s10/
│   ├── Main.java
│   └── prompt/
│       ├── SystemPrompt.java     # 结构化 prompt
│       └── PromptBuilder.java    # Prompt 构建器
└── pom.xml
```

## SystemPrompt 结构

```java
public class SystemPrompt {
    private String role;           // 角色定义
    private List<String> guidelines; // 行为准则
    private List<String> constraints; // 硬性约束
    private String skillsAvailable; // 技能摘要
    private String memory;         // 记忆内容
    private String claudeMd;       // CLAUDE.md 内容
    private String dynamicContext; // 动态上下文
    private String memoryGuidance; // 记忆指导
}
```

## CLAUDE.md 加载

从以下位置加载：
- `~/.claude/CLAUDE.md` - 用户全局配置
- 项目根目录 `CLAUDE.md` - 项目配置
- 当前目录 `CLAUDE.md` - 本地配置

## 动态上下文

包含：
- 当前日期
- 工作目录
- 模型名称
- 操作系统

## 为什么要结构化

System prompt 不是普通说明文字，它是 agent harness 给模型构造的运行环境说明。

结构化后：
- 新增 section 不需要手工拼字符串
- 不同来源的信息有明确字段
- 便于调试和测试

## 本章的局限

- 没有 token 预算控制
- 没有自动裁剪
- 没有快照测试
