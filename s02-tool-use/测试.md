# 测试文档

这是一个测试 Markdown 文件。

## 功能说明

本项目是一个 Java 实现的 AI Agent 框架，包含以下模块：

- **s01-agent-loop**: 基础 Agent 循环实现
- **s02-tool-use**: 工具系统扩展
- **s03-todo-write**: Todo 管理工具
- **s04-subagent**: 子代理系统

## 使用方法

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, Agent!");
    }
}
```
