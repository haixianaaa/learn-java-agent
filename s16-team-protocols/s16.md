# s16: Team Protocols

本章实现团队协议系统，标准化队友间的通信协议。协议定义了请求和响应的格式。

## 运行方式

```bash
cd s16-team-protocols
mvn exec:java -Dexec.mainClass="com.claudecode.agent.s16.Main"
```

## 本章新增能力

- 新增 `ProtocolRegistry` 管理协议
- 新增 `ProtocolHandler` 处理协议请求
- 标准化的请求/响应格式
- 支持多种协议类型

## 代码结构

```text
s16-team-protocols/
├── src/main/java/com/claudecode/agent/s16/
│   ├── Main.java
│   └── protocol/
│       ├── ProtocolRequest.java  # 协议请求
│       ├── ProtocolResponse.java # 协议响应
│       ├── ProtocolHandler.java  # 协议处理器
│       └── ProtocolRegistry.java # 协议注册表
└── pom.xml
```

## 内置协议

| 协议 | 用途 |
|------|------|
| `plan_approval` | 计划审批 |
| `task_delegation` | 任务委派 |
| `shutdown_request` | 关闭请求 |
| `status_query` | 状态查询 |

## 协议请求

```java
public class ProtocolRequest {
    private String protocol;
    private Map<String, Object> data;
    private String from;
    private String to;
}
```

## 协议响应

```java
public class ProtocolResponse {
    private boolean approved;
    private String message;
    private Object result;
}
```

## 本章的局限

- 没有协议版本管理
- 没有协议发现
- 没有协议文档生成
